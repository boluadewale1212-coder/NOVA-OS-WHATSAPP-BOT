  ## ⚙️ RENDER DEPLOYMENT

  1. Create a **Web Service** from this GitHub repository.
  2. Use the repository root as the root directory.
  3. Set the build command to `npm install --omit=dev && npm install --prefix bot --omit=dev`.
  4. Set the start command to `npm start`.
  5. Add `SESSION_ID` and `OWNER_NUMBER` in the service environment. `BOT_NAME` is optional and defaults to `NOVA-OS`; `WOLVAREX_API_KEY` enables Instagram downloads.

  Keep `SESSION_ID` private. Do not commit `.env`; use `.env.example` as a key list.
